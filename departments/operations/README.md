# Operations

onboarding, builds, client ops

19 jobs. Stage: build.

## Onboarding
- `kickoff-pack` (solo): Welcome note, access checklist and project scaffold the day work starts.
- `access-collection` (assisted): Chase and verify every credential and key a build needs, stored as secrets only.
- `project-scaffolding` (solo): Stand up the repo, context files and plan for a new venture.

## Build Ops
- `document-extraction` (solo): Structured extraction from piles of documents at volume.
- `integration-builds` (assisted): Wire systems together: CRM, calendar, transcripts, payments.
- `data-migration` (human): Move and clean data between systems without losing a row; you press go.
- `portal-provisioning` (assisted): Spin up a scoped portal with live status per venture or client.
- `qa-and-verification` (solo): Verify every build against real data before anyone else sees it.
- `agent-evaluation` (solo): Test agent outputs against a benchmark before they touch real work.

## Reliability
- `monitoring-and-alerting` (solo): Watch every automation for failures and silent stalls.
- `cost-and-usage-tracking` (solo): Token and API spend tracked against budget; no surprise bills.
- `incident-response` (assisted): When something breaks: triage, root cause, fix, write the note.

## Client Comms
- `status-updates` (solo): Progress goes out before anyone has to ask for it.
- `meeting-follow-ups` (assisted): Call transcript to action items, assigned and tracked.
- `portal-sync` (assisted): Session summaries and deliverables flow into the portal automatically.

## Knowledge
- `transcript-processing` (solo): Every meeting becomes searchable, structured context.
- `context-maintenance` (solo): Per-venture brain files stay current as work happens.
- `sop-generation` (assisted): Turn delivered work into reusable playbooks.
- `handoff-docs` (assisted): Clean documentation when a system ships.
